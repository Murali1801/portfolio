# Changelog

## 0.1.0 (2026-11-15)

First release.

- Home page with a short first screen (name, one line, local clock) and a project index table.
- Index rows expand in place into live mini-demos: Tonal, Sheet, Tab, Masthead and a spec-mode toggle.
- Spec mode: press G or use the footer toggle to draw the 12-column grid and 8px baseline.
- Case-study pages with a 680px text column, full-bleed figures drawn at build time and a facts strip.
- Typed content collection for projects, `site.config.ts` and `src/styles/theme.css` for restyling.
- GitHub star counts fetched at build time with an offline fallback.
- Light and dark themes with no flash, sitemap, robots.txt, OG image, favicon, 404 page.
- Unit tests for colour maths, spring physics, settle-up, SVG output, clock and star fetching.
